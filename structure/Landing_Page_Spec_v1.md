## Marketing Website — Content & Structure

Version: 1.0

> ⚠️ Naming: เอกสารในโปรเจกต์ใช้ทั้ง "SanamSpace" และ "PlayCourt" — spec นี้ใช้ **SanamSpace** เป็นแบรนด์หลัก กรุณาเคาะชื่อสุดท้ายก่อน build (กระทบ logo, domain, meta, copy ทั้งหมด)

# 0. Page Info

- Objective: เปลี่ยนเจ้าของสนามทุกกีฬา → ทดลองใช้ฟรี / ดูแพ็กเกจ / ติดต่อทีมขาย
- Primary audience: เจ้าของ + ผู้จัดการสนามกีฬา (แบด, ฟุตบอล, ฟุตซอล, เทนนิส, พิคเคิลบอล, บาส, วอลเลย์)
- Primary CTA: **ทดลองใช้ฟรี 30 วัน**
- Secondary CTA: **ดูแพ็กเกจ** / **คุยกับทีมงาน (LINE)**
- Language: ไทยเป็นหลัก (เตรียม slot สำหรับ EN ภายหลัง)
- URL: `/` (marketing site แยกจาก app)
- Tech: Next.js + Tailwind (ตรงกับ stack หลัก)

## 04 Problem (Pain Points)

Heading
> ยังบริหารสนามด้วย LINE + สมุดจดอยู่ใช่ไหม?

Pain cards
- รับจองซ้ำซ้อน ทะเลาะกับลูกค้าหน้างาน
- นั่งตรวจสลิปทีละใบ เสียเวลา เสี่ยงสลิปปลอม
- ลูกค้าจองแล้วไม่มา (no-show) เสียรายได้ทุกวัน
- ข้อมูลลูกค้ากระจัดกระจาย ไม่รู้ว่าใครเป็นขาประจำ
- สิ้นเดือนปิดยอดที ไม่รู้รายได้จริง คอร์ทไหนคุ้ม

---

## 05 Solution / How It Works

Heading
> ให้ลูกค้าจองเองครบทุกขั้น คุณแค่ดูแลสนาม

Steps (4 ข้อ มี icon)
1. ลูกค้า Login ผ่าน LINE เลือกกีฬา สนาม วันเวลา
2. โอนเงิน + อัปสลิป ระบบตรวจให้อัตโนมัติ (กันสลิปซ้ำ)
3. ระบบยืนยันการจอง + เตือนก่อนถึงเวลาเล่นอัตโนมัติ
4. ลูกค้าเช็คอินด้วย QR หน้าสนาม

## 06 Sports Supported (จุดต่างหลัก)

Heading
> ระบบเดียว รองรับทุกกีฬา ปรับให้เข้ากับธุรกิจคุณ

Cards (แต่ละกีฬาโชว์ฟีเจอร์ที่ตรงจุด)
- แบดมินตัน — จองรายชั่วโมง, แพ็กเกจชั่วโมงเหมา, waitlist เวลาเต็ม
- ฟุตบอล / ฟุตซอล — เก็บมัดจำ, จองประจำรายสัปดาห์ (ก๊วนประจำ), จองทั้งสนาม
- เทนนิส — ระบบสมาชิก/คลับ, จองคอร์ส coach
- พิคเคิลบอล — open-play, หาเพื่อนเล่น, จัดอีเวนต์
- บาสเกตบอล / วอลเลย์บอล — จองเหมาคอร์ท, จัดทีม

Note (ดีไซน์): ใช้ tab หรือ filter ตามกีฬา เพื่อให้คนรู้สึก "ทำมาเพื่อกีฬาของฉัน"

## 07 Core Features

Heading
> ทุกอย่างที่สนามต้องใช้ อยู่ในที่เดียว

Feature blocks (icon + หัวข้อ + 1 บรรทัด)
- ปฏิทินจองอัจฉริยะ — กันจองซ้ำ, ดูทุกคอร์ท/สนามในจอเดียว
- ตรวจสลิปอัตโนมัติ — อ่านยอด/ธนาคาร, ตรวจสลิปซ้ำ, อนุมัติในคลิกเดียว
- ระบบมัดจำ — ลด no-show ของสนามราคาสูง
- จองประจำ — ก๊วนประจำจองล่วงหน้าได้เลย
- สมาชิก · Wallet · แพ็กเกจ — มัดใจขาประจำ เพิ่มยอดซ้ำ
- CRM + Broadcast — ยิงโปรผ่าน LINE หาลูกค้าที่หายไป
- รายงานรายได้ + Utilization — รู้ว่าคอร์ทไหน เวลาไหนทำเงิน
- White Label — แบรนด์ โลโก้ สี โดเมน เป็นของสนามคุณเอง

# 4. Conversion & Tracking

- ปุ่ม CTA หลักซ้ำทุกช่วงพับจอ (hero, หลัง features, หลัง pricing, final)
- Sticky CTA bar บนมือถือ
- Lead form: ชื่อสนาม, กีฬา, จำนวนคอร์ท/สนาม, เบอร์/LINE
- Event tracking: คลิก CTA, toggle ราคา, เปิด FAQ, ส่งฟอร์ม
- A/B test: headline hero + ราคา toggle default (เดือน vs ปี)

# 5. Build Notes

- 1 section = 1 component (reuse ปุ่ม CTA, การ์ดฟีเจอร์)
- Mobile-first (เจ้าของสนามเปิดจากมือถือเป็นหลัก)
- ดึง pricing จาก source เดียวกับ Feature_Matrix_v2 (อย่า hardcode ซ้ำ)
- เก็บ landing page ไว้ใน repo marketing แยกจาก app
- รูป mockup รอจาก UI/prototype (อ้างอิง naming PT-CUS / PT-OWN)
