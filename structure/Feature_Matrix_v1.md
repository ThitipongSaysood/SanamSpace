# Recommended Plan Positioning

Starter
- สนามเปิดใหม่
- 1 สาขา

Business
- สนามขนาดเล็กถึงกลาง
- มีสมาชิกประจำ

Pro
- สนามที่ทำ CRM และการตลาดจริงจัง

Enterprise
- Chain สนามหลายสาขา
- ต้องการ White Label เต็มรูปแบบ

# Architecture Rules

1. ห้าม Hardcode Feature ใน Source Code
2. ทุก Feature เปิดผ่าน Feature Flag
3. Add-on ต้องแยกจาก Plan หลัก
4. Enterprise สามารถ Override Feature ได้
5. Usage Based Billing รองรับในอนาคต
