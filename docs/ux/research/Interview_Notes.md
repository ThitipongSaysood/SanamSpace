# Interview Notes

## Purpose
- เป็น **template/โครงสำหรับเก็บ interview** กับเจ้าของสนาม (Owner/Staff) และผู้เล่น เพื่อ validate personas, journey และ pain points
- หมายเหตุ: **assumption/template — ยังไม่มีข้อมูลสัมภาษณ์จริง** ทุกบันทึกด้านล่างเป็นโครงให้กรอก ไม่ใช่ผลวิจัย

## Summary
- เอกสารนี้ยังไม่มี data จริง ใช้เป็นแม่แบบเก็บข้อมูล
- แยกชุดคำถามเป็น 2 กลุ่ม: Owner/Staff และ Player
- เป้าหมาย: ยืนยัน pain (จองทับ, ตรวจสลิป, ข้อมูลลูกค้า, คอร์ตว่าง) และความเต็มใจจ่ายตาม plan

## Details

### โครงบันทึกต่อ 1 การสัมภาษณ์ (กรอกซ้ำต่อผู้ให้สัมภาษณ์)
- รหัส/ชื่อย่อผู้ให้สัมภาษณ์:
- บทบาท: Owner / Staff / Player / ผู้จัดก๊วน
- ประเภทสนาม & จำนวนสาขา/คอร์ต:
- วันที่ / ผู้สัมภาษณ์:
- ช่องทางจองที่ใช้อยู่ตอนนี้:
- ระบบ/เครื่องมือที่ใช้ตอนนี้ (LINE, สมุด, Excel, แอปอื่น):
- Pain เด่น 3 ข้อ (คำพูดจริง — verbatim quote):
- สิ่งที่อยากได้มากที่สุด:
- ความเต็มใจจ่าย / plan ที่สนใจ:
- ข้อสังเกต/insight:
- Action item / สิ่งที่ต้อง validate ต่อ:

### ชุดคำถามสำหรับ Owner / Staff
- ตอนนี้รับจองและจัดตารางคอร์ตอย่างไร เคยเจอจองทับเวลาไหม บ่อยแค่ไหน
- ขั้นตอนยืนยันการจ่าย/ตรวจสลิปทำอย่างไร ใช้เวลาเท่าไรต่อวัน เคยเจอสลิปปลอม/ซ้ำไหม
- รู้ไหมว่าใครเป็นลูกค้าประจำ เก็บข้อมูลลูกค้าไว้ที่ไหน เคยเอามาทำการตลาดไหม
- ช่วงเวลาไหนคอร์ตว่างบ่อย ทำอะไรเพื่อเติมคิวบ้าง
- งานช่วง peak ที่หนักที่สุดคืออะไร มี Staff กี่คน แบ่งหน้าที่อย่างไร
- ดูรายได้/อัตราการใช้คอร์ตจากไหน อยากเห็นรายงานอะไร
- ถ้ามีระบบช่วยจอง+ตรวจสลิป+ข้อมูลลูกค้า จะจ่ายเท่าไรต่อเดือน อะไรคือ deal-breaker

### ชุดคำถามสำหรับ Player / ผู้จัดก๊วน
- เล่นบ่อยแค่ไหน จองคอร์ตอย่างไรในปัจจุบัน เจอปัญหาอะไร
- ตอนจ่ายเงินทำอย่างไร รู้สึกอย่างไรกับการรอยืนยันสลิป
- เคยลืมเวลาที่จองไหม อยากได้แจ้งเตือนแบบไหน
- เป็นสมาชิกสนามไหนไหม อะไรทำให้กลับไปจองซ้ำ (ส่วนลด/แต้ม/wallet/ความสะดวก)
- (ผู้จัดก๊วน) จองให้ก๊วนอย่างไร เก็บเงินเพื่อนอย่างไร อยากได้ฟีเจอร์อะไร
- ถ้ามีแอปจองผ่าน LINE + เติม wallet + สะสมแต้ม จะใช้ไหม อะไรทำให้เลิกใช้

### แนวทางการเก็บ (assumption)
- จำนวนตัวอย่างเป้าหมาย: Owner/Staff 5–8 ราย, Player 8–12 ราย — **สมมติฐาน** ปรับตามทรัพยากร
- รูปแบบ: สัมภาษณ์ตัวต่อตัว ~30–45 นาที, ขออนุญาตอัดเสียง
- คัด recruit จากสนามกลุ่มเป้าหมายใน PRD (แบด/ฟุตซอล/เทนนิส/pickleball)
