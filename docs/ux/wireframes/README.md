# Wireframes

เก็บไฟล์ wireframe (`.png`) แยกตามฝั่ง: `customer/` · `owner/` · `super-admin/`

## Naming Standard

```
WF-<APP>-<NNN>-<ScreenName>.png
```

| App | Prefix | ตัวอย่าง |
|---|---|---|
| Customer | `WF-CUS-` | `WF-CUS-001-Login.png`, `WF-CUS-002-Home.png`, `WF-CUS-003-Venue.png` |
| Owner | `WF-OWN-` | `WF-OWN-001-Dashboard.png` |
| Super Admin | `WF-ADM-` | `WF-ADM-001-Organizations.png` |

> เลข `NNN` เรียงตามลำดับจอในแต่ละฝั่ง และควร map กับ Screen ID ในเอกสาร (เช่น `WF-CUS-001` ↔ `CUS-AUTH-001`)
