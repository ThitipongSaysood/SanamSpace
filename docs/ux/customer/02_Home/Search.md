# CUS-HOME-003 · Search

## Objective
หน้าค้นหาสนาม/คอร์ทตามคำค้น ชนิดกีฬา วันเวลา และช่วงราคา เพื่อให้ผู้ใช้เจอสนามที่ตรงความต้องการเร็วขึ้น

## User Story
> As a **ลูกค้า (Customer)**, I want **ค้นหาสนามด้วยคำค้นและตัวกรองชนิดกีฬา/วันเวลา**, so that **เจอสนามว่างที่ตรงเวลาและงบของฉันได้ทันที**.

## Entry Point
- แตะ "ค้นหาสนาม" หรือช่องค้นหา จาก Home (CUS-HOME-001)
- แตะไอคอนค้นหาจาก Venue List (CUS-HOME-002)

## Exit Point
- แตะผลลัพธ์สนาม → Venue Detail (CUS-VENUE-001)
- กดล้างตัวกรอง → กลับสู่สถานะค้นหาเริ่มต้น

## Components
- ช่องค้นหา (พิมพ์ชื่อสนาม/ทำเล)
- ตัวกรองชนิดกีฬา (ชิป: แบดมินตัน, ฟุตบอล, เทนนิส ฯลฯ)
- ตัวเลือกวันที่ + ช่วงเวลา (เช่น 16:00–20:00)
- ตัวกรองช่วงราคา
- รายการผลลัพธ์เป็นการ์ดสนาม + ปุ่มล้างตัวกรอง

## Validation Rules
- คำค้น: ตัดช่องว่างหัวท้าย, รองรับค้นหาว่าง (แสดงตามตัวกรอง)
- วันที่ต้องไม่เป็นอดีต; เวลาเริ่มต้องน้อยกว่าเวลาสิ้นสุด
- ผลลัพธ์ถูก scope ด้วย organization_id

## API Dependencies
- `GET /courts` — ค้นหา/กรองคอร์ท (query: คำค้น, ชนิดกีฬา, วันเวลา, ราคา)
- `GET /branches` — กรองตามสาขา/ทำเล
- `GET /courts/{id}/schedules` — ตรวจช่วงเวลาว่างเมื่อกรองตามเวลา

## Edge Cases
- ไม่พบผลลัพธ์ → empty state "ไม่พบสนามที่ตรงเงื่อนไข" + ปุ่มล้างตัวกรอง
- กำลังค้นหา → skeleton/spinner ในรายการ
- พิมพ์เร็วต่อเนื่อง → debounce ก่อนยิง API
- เครือข่ายล่ม → error + ปุ่มลองใหม่ โดยคงคำค้น/ตัวกรองไว้

## Success Criteria
- ค้นหาด้วยคำค้น + ตัวกรองแล้วได้ผลลัพธ์ที่ถูกต้องและเข้าต่อได้
- กรองวันเวลาแล้วผลลัพธ์สะท้อนสนามที่ว่างจริง
- มี debounce และ loading/empty/error state ครบ
