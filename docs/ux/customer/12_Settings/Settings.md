# CUS-SET-001 · Settings

## Objective
- เป็นศูนย์กลางการตั้งค่าแอป: ภาษา, การแจ้งเตือน, บัญชี, ความเป็นส่วนตัว, เกี่ยวกับแอป
- นำทางไปจอตั้งค่าย่อย และแสดงข้อมูลเวอร์ชัน/นโยบาย

## User Story
> As a **Customer**, I want **เข้าถึงการตั้งค่าทั้งหมดของแอปจากที่เดียว**, so that **ปรับแต่งการใช้งานและจัดการบัญชีได้สะดวก**.

## Entry Point
- จาก Profile (CUS-PROFILE-001) เมนู "ตั้งค่า"

## Exit Point
- "ภาษา" → CUS-SET-002 (Language)
- "บัญชี" → CUS-SET-003 (Account)
- "การแจ้งเตือน" → CUS-NOTI-002 (Notification Settings)
- ย้อนกลับ → CUS-PROFILE-001

## Components
- กลุ่มเมนูตั้งค่า: ภาษา (แสดงภาษาปัจจุบัน), การแจ้งเตือน, บัญชี
- กลุ่มความเป็นส่วนตัว/กฎหมาย: นโยบายความเป็นส่วนตัว, ข้อกำหนดการใช้งาน
- กลุ่มเกี่ยวกับ: เวอร์ชันแอป, ติดต่อสนาม/ช่วยเหลือ
- รายการแบบ list item พร้อมไอคอนและ chevron นำทาง

## Validation Rules
- แสดงค่าปัจจุบันของแต่ละการตั้งค่า (เช่น ภาษาที่ใช้อยู่)
- ลิงก์นโยบาย/ข้อกำหนดเปิดหน้า/เว็บที่กำหนดโดยสนาม (tenant)
- เมนูที่ต้องล็อกอิน (บัญชี) แสดงเฉพาะเมื่อล็อกอินแล้ว

## API Dependencies
- — (ค่าตั้งค่าอ่านจาก local/profile; เมนูย่อยเรียก API ของตัวเอง)

## Edge Cases
- ลิงก์นโยบาย/ช่วยเหลือเปิดไม่ได้ → toast "เปิดลิงก์ไม่สำเร็จ"
- เวอร์ชันใหม่พร้อมใช้งาน → แสดงป้าย "อัปเดต" (ถ้ามีกลไกเช็ก)
- ออฟไลน์ → เมนูที่ไม่ต้องเน็ตยังใช้ได้, เมนูออนไลน์แจ้งสถานะ

## Success Criteria
- แสดงเมนูตั้งค่าครบและนำไปจอย่อยถูกต้อง
- ค่าปัจจุบัน (ภาษา ฯลฯ) แสดงตรงกับที่ตั้งไว้
- ลิงก์นโยบาย/ข้อกำหนด/เวอร์ชันแสดงถูกต้อง
- เข้า CUS-SET-002, CUS-SET-003, CUS-NOTI-002 ได้จากหน้านี้
