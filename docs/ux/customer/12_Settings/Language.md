# CUS-SET-002 · Language

## Objective
- ให้ลูกค้าเลือกภาษาของแอป (ไทย / อังกฤษ) และนำไปใช้ทันทีทั้งแอป
- บันทึกค่าภาษาเป็นค่ากำหนดของบัญชี/อุปกรณ์

## User Story
> As a **Customer**, I want **เลือกภาษาที่ใช้ในแอป**, so that **ใช้งานแอปในภาษาที่ฉันถนัด**.

## Entry Point
- จาก CUS-SET-001 (Settings) เมนู "ภาษา"

## Exit Point
- เลือกภาษา → นำไปใช้ทันที + กลับ CUS-SET-001 (หรือคงอยู่พร้อมเครื่องหมายเลือก)
- ย้อนกลับ → CUS-SET-001 โดยไม่เปลี่ยน

## Components
- รายการภาษาแบบ single-select (radio): ภาษาไทย, English
- เครื่องหมายถูกบนภาษาที่ใช้อยู่
- ตัวอย่างผลทันที (ข้อความ UI เปลี่ยนตามที่เลือก)

## Validation Rules
- เลือกได้ครั้งละ 1 ภาษาเท่านั้น
- รองรับเฉพาะภาษาที่แอปมีไฟล์แปล (ไทย/อังกฤษ) ตามฟอนต์ Prompt/Inter ของ Design System
- ค่าภาษาบันทึกต่อบัญชีและ/หรืออุปกรณ์ คงอยู่หลังปิดแอป

## API Dependencies
- `PUT /api/v1/customers/{id}` — บันทึกภาษาที่เลือกเป็นค่ากำหนดบัญชี (ถ้า sync ข้ามอุปกรณ์)
- — (อาจเก็บ local อย่างเดียวถ้าไม่ sync)

## Edge Cases
- บันทึกค่ากับ backend ล้มเหลว → ยังใช้ภาษาที่เลือกใน local + retry sync ภายหลัง
- ข้อความบางส่วนไม่มีคำแปล → fallback เป็นภาษาเริ่มต้น (ไทย)
- เปลี่ยนภาษาขณะมีฟอร์มค้าง → ข้อความเปลี่ยนแต่ค่าที่กรอกคงอยู่
- ออฟไลน์ → เปลี่ยนภาษาใน local ได้ทันที, sync เมื่อกลับมาออนไลน์

## Success Criteria
- เลือกภาษาแล้ว UI เปลี่ยนทันทีทั้งแอป
- ภาษาที่เลือกถูกบันทึกและคงอยู่หลังเปิดแอปใหม่
- เครื่องหมายเลือกตรงกับภาษาที่ใช้อยู่
- กรณี sync ล้มเหลวยังใช้ภาษาที่เลือกได้
