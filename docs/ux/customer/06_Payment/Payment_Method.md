# CUS-PAY-001 · Payment Method

## Objective
- ให้ลูกค้าเลือกวิธีชำระเงินสำหรับการจองที่สร้างไว้แล้ว
- แสดงยอดที่ต้องชำระและช่องทางที่สนามเปิดใช้งาน (ตามแพ็กเกจของสนาม)
- พาลูกค้าไปยังขั้นตอนชำระเงินตามวิธีที่เลือก

## User Story
> As a **ลูกค้า (Customer)**, I want **เลือกวิธีชำระเงินสำหรับการจอง**, so that **ชำระเงินยืนยันการจองได้ในช่องทางที่สะดวก**.

## Entry Point
- มาจากจอสรุปการจอง (CUS-BOOK-001) หลังกดยืนยัน "ดำเนินการชำระเงิน"

## Exit Point
- เลือก "โอนเงิน / PromptPay" → ไปจอโอนเงิน (CUS-PAY-002)
- เลือก Wallet และยอดพอ → ตัด Wallet สำเร็จ → ไปจอสถานะ (CUS-PAY-004)
- เลือก Card (เฉพาะสนาม Pro+) → ไปหน้า Payment Gateway → กลับมาที่ (CUS-PAY-004)
- กดยกเลิก → กลับจอสรุปการจอง (CUS-BOOK-001)

## Components
- ส่วนหัวแสดงรหัสการจอง + สนาม/คอร์ต/วันเวลา
- การ์ดสรุปยอดที่ต้องชำระ (บาท)
- รายการตัวเลือกวิธีชำระเงิน (radio): PromptPay / โอนผ่านธนาคาร, บัตรเครดิต-เดบิต, Wallet (แสดงยอดคงเหลือ)
- ป้ายตัวเลือกที่ปิดใช้งานตามแพ็กเกจสนาม (เช่น Card สำหรับ Pro+)
- ปุ่ม "ดำเนินการต่อ" และ "ยกเลิก"
- ตัวนับเวลาคงเหลือก่อนการจองหมดอายุ (hold)

## Validation Rules
- ต้องเลือกวิธีชำระเงิน 1 รายการก่อนกด "ดำเนินการต่อ"
- การจองต้องอยู่สถานะรอชำระเงิน (pending) และยังไม่หมดอายุ
- เลือก Wallet ได้เฉพาะเมื่อยอดคงเหลือ ≥ ยอดที่ต้องชำระ
- ยอดชำระต้องเท่ากับยอดการจอง (รวมส่วนลด/คูปองที่ใช้แล้ว)

## API Dependencies
- `GET /api/v1/bookings/{id}` — ดึงรายละเอียดการจองและยอดที่ต้องชำระ
- `GET /api/v1/wallets` — ดึงยอดคงเหลือ Wallet (กรณีสนามเปิด Wallet)
- `POST /api/v1/payments` — สร้างรายการชำระเงินตามวิธีที่เลือก

## Edge Cases
- การจองหมดอายุ (hold timeout) ระหว่างเลือกวิธีชำระ → แจ้งเตือนและกลับไปจองใหม่
- ยอด Wallet ไม่พอ → ปิดตัวเลือก Wallet พร้อมข้อความอธิบาย
- สนามไม่เปิดช่องทางใดเลยนอกจากโอนเงิน → แสดงเฉพาะ PromptPay/โอน
- โหลดข้อมูลการจอง/Wallet ล้มเหลว → แสดงสถานะ error พร้อมปุ่มลองใหม่
- มีรายการ payment ค้างของการจองเดิม → ใช้รายการเดิมแทนการสร้างซ้ำ

## Success Criteria
- เลือกวิธีชำระแล้วระบบสร้างรายการ payment และนำทางไปขั้นตอนถัดไปถูกต้องตามวิธีที่เลือก
- ตัวเลือกที่สนามไม่เปิด/ยอดไม่พอ ถูกปิดและไม่สามารถส่งต่อได้
- เมื่อการจองหมดอายุ ระบบบล็อกการชำระและแจ้งผู้ใช้ชัดเจน
