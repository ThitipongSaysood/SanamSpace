# CUS-PAY-002 · Transfer

## Objective
- แสดงข้อมูลสำหรับการโอนเงิน (PromptPay QR / เลขบัญชีธนาคารของสนาม)
- แสดงยอดที่ต้องโอนให้ตรงกับการจอง พร้อมเวลาที่ต้องชำระภายใน
- พาลูกค้าไปอัปโหลดสลิปเพื่อยืนยันการโอน

## User Story
> As a **ลูกค้า (Customer)**, I want **เห็น QR PromptPay และเลขบัญชีพร้อมยอดที่ต้องโอน**, so that **โอนเงินได้ถูกต้องและนำหลักฐานไปยืนยันการจอง**.

## Entry Point
- มาจากจอเลือกวิธีชำระเงิน (CUS-PAY-001) เมื่อเลือก "PromptPay / โอนผ่านธนาคาร"

## Exit Point
- กด "อัปโหลดสลิป" → ไปจออัปโหลดสลิป (CUS-PAY-003)
- กดย้อนกลับ → กลับจอเลือกวิธีชำระเงิน (CUS-PAY-001)
- ปล่อยจนหมดเวลา → การจองหมดอายุ กลับ (CUS-BOOK-001)

## Components
- ภาพ QR PromptPay ของสนาม (ปุ่มบันทึก/แชร์ QR)
- กล่องเลขบัญชีธนาคาร + ชื่อบัญชี + ปุ่มคัดลอก
- ยอดที่ต้องโอน (เน้นตัวเลข) + ปุ่มคัดลอกจำนวนเงิน
- ตัวนับเวลาที่ต้องชำระภายใน (countdown)
- ขั้นตอนแนะนำ "โอนแล้วถ่ายสลิปเพื่ออัปโหลด"
- ปุ่มหลัก "อัปโหลดสลิป" และปุ่มย้อนกลับ

## Validation Rules
- รายการ payment ต้องมีอยู่และอยู่สถานะรอชำระ (pending)
- ยอดที่แสดงต้องเท่ากับยอดการจองเสมอ (อ่านจากระบบ ไม่ให้แก้)
- ต้องมีข้อมูลบัญชี/QR ของสนามจึงจะแสดงจอนี้ได้
- ต้องยังไม่หมดเวลาชำระจึงจะไปขั้นตอนอัปโหลดสลิปได้

## API Dependencies
- `GET /api/v1/payments` — ดึงรายการ payment ปัจจุบันและสถานะ
- `GET /api/v1/bookings/{id}` — ยืนยันยอดและเวลาหมดอายุของการจอง

## Edge Cases
- สนามยังไม่ตั้งค่าบัญชี/QR → แสดงข้อความให้ติดต่อสนาม และซ่อนปุ่มอัปโหลด
- หมดเวลาชำระระหว่างอยู่หน้านี้ → ปิดปุ่มอัปโหลดและแจ้งการจองหมดอายุ
- payment ถูกยกเลิก/เปลี่ยนสถานะจากที่อื่น → รีเฟรชสถานะและแจ้งผู้ใช้
- โหลด QR ไม่สำเร็จ → แสดงเลขบัญชีสำรองพร้อมปุ่มลองใหม่
- ลูกค้าโอนยอดผิด → แจ้งเตือนตรวจสอบยอดก่อนกดอัปโหลดสลิป

## Success Criteria
- ลูกค้าเห็น QR/เลขบัญชีและยอดที่ตรงกับการจอง คัดลอกได้สะดวก
- กด "อัปโหลดสลิป" แล้วไปจอ CUS-PAY-003 พร้อม payment id ที่ถูกต้อง
- เมื่อหมดเวลาหรือสนามไม่มีบัญชี ระบบบล็อกการดำเนินต่ออย่างชัดเจน
