# CUS-PAY-005 · Refund

## Objective
- ให้ลูกค้ายื่นคำขอคืนเงินสำหรับการจอง/การชำระที่ชำระแล้ว
- แสดงยอดที่ขอคืนได้ตามเงื่อนไข และติดตามสถานะคำขอคืนเงิน
- เป็นจุดยื่นคำขอฝั่งลูกค้า โดยการอนุมัติทำใน Owner portal

## User Story
> As a **ลูกค้า (Customer)**, I want **ยื่นคำขอคืนเงินสำหรับการจองที่จ่ายแล้วและติดตามสถานะ**, so that **ได้รับเงินคืนตามเงื่อนไขเมื่อยกเลิกหรือเปลี่ยนแผน**.
>
> หมายเหตุ: การอนุมัติคืนเงินทำโดยเจ้าหน้าที่ (Cashier/Owner) ใน Owner portal — จอนี้เป็นการ "ขอคืนเงินและดูสถานะ" ฝั่งลูกค้า และเป็นฟีเจอร์ของแพ็กเกจ Business+ เท่านั้น

## Entry Point
- มาจากจอรายละเอียด/ยืนยันการจอง (CUS-BOOK-002) ที่ชำระเงินแล้ว เมื่อกด "ขอคืนเงิน"

## Exit Point
- ส่งคำขอสำเร็จ → ไปจอสถานะการชำระเงิน/คำขอ (CUS-PAY-004) สถานะ "รอคืนเงิน"
- กดยกเลิก → กลับจอรายละเอียดการจอง (CUS-BOOK-002)

## Components
- การ์ดสรุปการจองและยอดที่ชำระไปแล้ว
- ยอดที่ขอคืนได้ (ตามนโยบาย/ค่าธรรมเนียมยกเลิก)
- ตัวเลือกเหตุผลการขอคืนเงิน + ช่องหมายเหตุ
- แสดงช่องทางรับเงินคืน (บัญชี/Wallet)
- สถานะคำขอ (รอคืนเงิน / อนุมัติแล้ว / ปฏิเสธ)
- ปุ่ม "ส่งคำขอคืนเงิน" และปุ่มยกเลิก

## Validation Rules
- การจองต้องมี payment สถานะสำเร็จจึงขอคืนเงินได้
- ต้องเลือกเหตุผลการขอคืนเงินก่อนส่ง
- ยอดขอคืนต้องไม่เกินยอดที่ชำระจริง (หักค่าธรรมเนียมตามนโยบาย)
- ต้องอยู่ในกรอบเวลาที่นโยบายอนุญาตให้คืนเงิน
- ฟีเจอร์เปิดเฉพาะสนามแพ็กเกจ Business ขึ้นไป (Refund Management)

## API Dependencies
- `GET /api/v1/payments` — ตรวจ payment ที่ชำระสำเร็จเพื่อขอคืน
- `POST /api/v1/refunds` — สร้างคำขอคืนเงิน
- `POST /api/v1/refunds/{id}/approve` — เจ้าหน้าที่อนุมัติ (Owner portal — แสดงผลสถานะที่ฝั่งลูกค้า)

## Edge Cases
- สนามไม่เปิดฟีเจอร์ Refund (ต่ำกว่า Business) → ซ่อน/ปิดปุ่มขอคืนเงิน
- เลยกรอบเวลานโยบายคืนเงิน → แจ้งว่าไม่สามารถขอคืนได้
- มีคำขอคืนเงินค้างอยู่แล้ว → แสดงสถานะเดิม ไม่ให้ส่งซ้ำ
- คำขอถูกปฏิเสธโดยเจ้าหน้าที่ → แสดงเหตุผลและช่องทางติดต่อสนาม
- payment ยังไม่สำเร็จ/ถูกยกเลิก → ไม่อนุญาตให้ขอคืนเงิน
- ส่งคำขอล้มเหลว/เน็ตหลุด → ให้ลองใหม่โดยไม่สร้างคำขอซ้ำ

## Success Criteria
- ลูกค้ายื่นคำขอคืนเงินที่เข้าเงื่อนไขได้สำเร็จ และเห็นสถานะ "รอคืนเงิน"
- ยอดขอคืนคำนวณตามนโยบายและไม่เกินยอดที่ชำระจริง
- เมื่อเจ้าหน้าที่อนุมัติ/ปฏิเสธ สถานะฝั่งลูกค้าอัปเดตและแสดงเหตุผลถูกต้อง
- สนามที่ไม่เปิดฟีเจอร์ Refund ไม่สามารถเข้าถึงจอนี้ได้
