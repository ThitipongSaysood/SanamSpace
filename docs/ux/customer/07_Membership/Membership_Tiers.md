# CUS-MEMBER-002 · Membership Tiers

## Objective
- เปรียบเทียบสิทธิประโยชน์ของทั้ง 3 ระดับ: Silver / Gold / Platinum แบบเคียงข้างกัน
- ระบุเงื่อนไขการเลื่อนระดับ (คะแนน/ยอดใช้จ่ายสะสม) ของแต่ละระดับ
- ไฮไลต์ระดับปัจจุบันของลูกค้า และชี้ทางไปอัปเกรด

## User Story
> As a **Customer**, I want **เปรียบเทียบสิทธิของแต่ละระดับสมาชิก**, so that **ตัดสินใจได้ว่าจะสะสมเพื่อเลื่อนระดับไปยังระดับใด**.

## Entry Point
- จาก CUS-MEMBER-001 (Membership Overview) กด "ดูระดับทั้งหมด"

## Exit Point
- กด "อัปเกรดเป็น Gold/Platinum" → CUS-MEMBER-003 (Upgrade Membership)
- ย้อนกลับ → CUS-MEMBER-001 (Membership Overview)

## Components
- Tier comparison: การ์ด/ตาราง 3 คอลัมน์ (Silver, Gold, Platinum) พร้อมสีประจำระดับ
- แถวสิทธิประโยชน์: ส่วนลดต่อการจอง, อัตราสะสมคะแนน, สิทธิจองล่วงหน้า/จองก่อน, ของรางวัล/สิทธิพิเศษ
- เงื่อนไขเลื่อนระดับต่อ tier (คะแนน/ยอดสะสมขั้นต่ำ)
- ป้าย "ระดับปัจจุบัน" บนคอลัมน์ของลูกค้า
- ปุ่ม CTA "อัปเกรด" ใต้ระดับที่สูงกว่าปัจจุบัน

## Validation Rules
- ไฮไลต์ระดับปัจจุบันตาม membership ของลูกค้าเท่านั้น
- ปุ่มอัปเกรดแสดงเฉพาะระดับที่สูงกว่าระดับปัจจุบัน (ไม่ให้ downgrade)
- ข้อมูลสิทธิ/เงื่อนไขดึงจาก config ของสนาม (tenant) ไม่ hardcode
- ระดับ Platinum (สูงสุด) ไม่แสดงปุ่มอัปเกรด

## API Dependencies
- `GET /api/v1/memberships` — รายการระดับ/สิทธิประโยชน์และระดับปัจจุบันของลูกค้า

## Edge Cases
- สนามกำหนดสิทธิบางระดับไม่ครบ → ซ่อนแถวที่ไม่มีข้อมูล
- โหลด config ระดับล้มเหลว → แสดง error + ปุ่ม "ลองใหม่"
- ลูกค้าเป็น Platinum อยู่แล้ว → ทุกปุ่มอัปเกรดถูกซ่อน แสดง "คุณอยู่ระดับสูงสุด"
- จำนวนระดับเปลี่ยนตามนโยบายสนาม → layout รองรับ scroll แนวนอน

## Success Criteria
- แสดงเปรียบเทียบสิทธิครบทั้ง 3 ระดับชัดเจน
- ไฮไลต์ระดับปัจจุบันถูกต้อง
- ปุ่มอัปเกรดนำไป CUS-MEMBER-003 เฉพาะระดับที่สูงกว่า
- ระดับสูงสุดไม่แสดง CTA อัปเกรด
