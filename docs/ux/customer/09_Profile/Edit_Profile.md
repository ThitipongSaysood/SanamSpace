# CUS-PROFILE-002 · Edit Profile

## Objective
- ให้ลูกค้าแก้ไขข้อมูลส่วนตัว: ชื่อ, รูปโปรไฟล์, เบอร์โทร, อีเมล, เพศ/วันเกิด (ถ้ามี)
- บันทึกข้อมูลกลับสู่ระบบและสะท้อนผลในหน้า Profile

## User Story
> As a **Customer**, I want **แก้ไขข้อมูลส่วนตัวของฉัน**, so that **ข้อมูลติดต่อและโปรไฟล์ถูกต้องและเป็นปัจจุบัน**.

## Entry Point
- จาก CUS-PROFILE-001 (Profile) ปุ่ม "แก้ไขโปรไฟล์"

## Exit Point
- บันทึกสำเร็จ → กลับ CUS-PROFILE-001 พร้อมข้อมูลอัปเดต + toast สำเร็จ
- ยกเลิก/ย้อนกลับ → CUS-PROFILE-001 โดยไม่บันทึก (เตือนถ้ามีการแก้ค้าง)

## Components
- อัปโหลด/เปลี่ยนรูปโปรไฟล์ (กล้อง/แกลเลอรี)
- ฟอร์ม: ชื่อ-นามสกุล, เบอร์โทร, อีเมล, เพศ, วันเกิด
- ป้ายกำกับ field ที่แก้ไม่ได้ (เช่น เบอร์ที่ผูก LINE Login) เป็น read-only
- ปุ่มหลัก "บันทึก" / ปุ่มรอง "ยกเลิก"

## Validation Rules
- ชื่อห้ามว่าง
- อีเมลต้องเป็นรูปแบบที่ถูกต้อง (ถ้ากรอก)
- เบอร์โทรเป็นรูปแบบไทย 10 หลัก (ถ้าแก้ไขได้)
- รูปโปรไฟล์: ชนิดไฟล์ภาพ (jpg/png) และขนาดไม่เกิน limit ที่กำหนด
- ปุ่มบันทึก disable จนกว่าจะมีการแก้ไขและผ่าน validation

## API Dependencies
- `GET /api/v1/customers/{id}` — โหลดข้อมูลเดิมเข้าฟอร์ม
- `PUT /api/v1/customers/{id}` — บันทึกข้อมูลที่แก้ไข

## Edge Cases
- อีเมล/เบอร์ซ้ำกับบัญชีอื่น → inline error จาก backend (409)
- อัปโหลดรูปล้มเหลว → คงรูปเดิม + แจ้งให้ลองใหม่
- บันทึกล้มเหลว (5xx) → คงข้อมูลในฟอร์ม + ปุ่ม "ลองใหม่"
- ย้อนกลับขณะมีการแก้ค้าง → ถามยืนยัน "ทิ้งการแก้ไข?"
- ออฟไลน์ → ปิดปุ่มบันทึก + แจ้งสถานะเชื่อมต่อ

## Success Criteria
- แก้ไขข้อมูลและบันทึกสำเร็จ สะท้อนในหน้า Profile ทันที
- validation บล็อกข้อมูลไม่ถูกต้องก่อนส่ง
- field read-only แก้ไม่ได้
- กรณีล้มเหลวไม่สูญเสียข้อมูลที่กรอก
