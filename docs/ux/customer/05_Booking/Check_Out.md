# CUS-BOOK-006 · Check Out

## Objective
- ปิดการใช้งานคอร์ทเมื่อลูกค้าเล่นเสร็จ ทำให้ booking สมบูรณ์ (Completed) และ slot ว่างตามจริง
- สรุปการใช้งาน (เวลาเข้า–ออก) และเปิดทางไปยังขั้นตอนถัดไป เช่น ให้คะแนน/จองซ้ำ

## User Story
> As a **Customer**, I want **เช็คเอาท์เมื่อใช้คอร์ทเสร็จและเห็นสรุปการใช้งาน**, so that **การจองถูกปิดอย่างถูกต้องและผมจองครั้งต่อไปได้ง่าย**.

## Entry Point
- จาก CUS-BOOK-005 (Check In) เมื่อหมดเวลาจอง/ลูกค้าเล่นเสร็จ
- จาก CUS-BOOK-003 (Booking History) การ์ดที่ checked_in → ปุ่ม "เช็คเอาท์"
- พนักงานสแกน QR/กดเช็คเอาท์ฝั่ง staff

## Exit Point
- เช็คเอาท์สำเร็จ → booking = completed, แสดงสรุปการใช้งาน → กลับ CUS-BOOK-003 (แท็บ Completed)
- (Business+) ปุ่ม "จองซ้ำ" → CUS-BOOK-001 แบบ pre-filled

## Components
- สรุปการใช้งาน: ชื่อคอร์ท, วันที่, เวลาเข้า (check-in) – เวลาออก (check-out), ระยะเวลาที่ใช้จริง
- แบดจ์สถานะ "เสร็จสิ้น (Completed)"
- ยอดสุทธิ/ค่าใช้จ่ายเพิ่มเติม (ถ้ามี เช่น เกินเวลา)
- ปุ่มหลัก "เสร็จสิ้น" → กลับ History; ปุ่มรอง (Business+) "จองซ้ำ"
- (ทางเลือก) ลิงก์ให้คะแนน/รีวิวสนาม

## Validation Rules
- เช็คเอาท์ได้เฉพาะ booking สถานะ checked_in เท่านั้น
- เช็คเอาท์ได้ครั้งเดียวต่อ booking (ไม่ซ้ำ)
- บันทึก check_out timestamp ≥ check_in timestamp เสมอ
- หากเลยเวลาจอง ระบบอาจคิดค่าเกินเวลาตามนโยบายสนามก่อนปิด booking

## API Dependencies
- `POST /api/v1/bookings/{id}/checkout` — บันทึกการเช็คเอาท์และปิด booking
- `GET /api/v1/bookings/{id}` — ดึงข้อมูลเวลาเข้า/รายละเอียดเพื่อแสดงสรุป

## Edge Cases
- พยายามเช็คเอาท์ก่อนเช็คอิน (สถานะไม่ใช่ checked_in) → ปฏิเสธ พร้อมข้อความเหตุผล
- เช็คเอาท์ซ้ำ → คืน 409/แจ้ง "เช็คเอาท์ไปแล้ว" (idempotent)
- ลืมเช็คเอาท์จนเลยเวลา → ระบบ auto-checkout เมื่อสิ้นสุดช่วงจอง + ทำเครื่องหมาย completed
- เกินเวลา (overtime) → แสดงค่าใช้จ่ายเพิ่มและช่องทางชำระก่อนปิด
- network error ระหว่างเช็คเอาท์ → ไม่เปลี่ยนสถานะ, ให้ลองใหม่
- จองซ้ำในแพ็กเกจ Starter (ไม่รองรับ Rebooking) → ซ่อนปุ่ม "จองซ้ำ"

## Success Criteria
- เช็คเอาท์แล้ว booking เปลี่ยนเป็น completed และ slot ว่างตามจริง
- สรุปแสดงเวลาเข้า–ออกและระยะเวลาที่ใช้จริงถูกต้อง
- เช็คเอาท์ซ้ำ/ก่อนเช็คอินไม่ทำให้สถานะผิดเพี้ยน (idempotent + validate)
- กรณีลืมเช็คเอาท์ ระบบปิด booking อัตโนมัติได้
