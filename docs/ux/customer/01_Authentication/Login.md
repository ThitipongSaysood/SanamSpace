# CUS-AUTH-001 · Login

## Objective
หน้าศูนย์กลางการเข้าสู่ระบบของลูกค้า ให้เลือกล็อกอินด้วย LINE / เบอร์โทร (OTP) / อีเมล เพื่อเข้าใช้งานแอปจองสนาม

## User Story
> As a **ลูกค้า (Customer)**, I want **เข้าสู่ระบบด้วย LINE เบอร์โทร หรืออีเมลได้ในจอเดียว**, so that **เริ่มจองสนามได้เร็วโดยไม่ต้องจำรหัสผ่านหลายชุด**.

## Entry Point
- เปิดแอปครั้งแรก / ยังไม่ได้ล็อกอิน จาก Splash (CUS-AUTH ก่อนหน้า)
- ถูกเด้งมาจากจอที่ต้องล็อกอิน เช่น จองสนาม (CUS-BOOK-001), Favorites (CUS-HOME-004)

## Exit Point
- สำเร็จ → Home (CUS-HOME-001) หรือกลับจอต้นทางที่ค้างไว้
- เลือก LINE → LINE Login (CUS-AUTH-002)
- ยังไม่มีบัญชี → สมัครสมาชิก / Register (CUS-AUTH-003)

## Components
- โลโก้แบรนด์ (Everyday Badminton) + หัวข้อ "เข้าสู่ระบบ"
- ปุ่ม "เข้าสู่ระบบด้วย LINE" (ปุ่มหลักสีเขียว)
- ปุ่ม "เข้าสู่ระบบด้วยเบอร์โทร" (OTP)
- ปุ่ม "เข้าสู่ระบบด้วยอีเมล"
- ลิงก์ท้ายจอ "ยังไม่มีบัญชี? สมัครสมาชิก"

## Validation Rules
- เบอร์โทร: ตัวเลขล้วน 10 หลัก ขึ้นต้น 0
- อีเมล: รูปแบบ email ถูกต้อง + รหัสผ่านไม่ว่าง
- ต้องเลือกอย่างน้อย 1 วิธี ปุ่ม disabled ระหว่างเรียก API

## API Dependencies
- `POST /auth/line/login` — ล็อกอินผ่าน LINE
- `GET /auth/me` — ดึงโปรไฟล์/ตรวจ session หลังล็อกอิน
- _หมายเหตุ: ช่องทางเบอร์โทร/อีเมล ใช้ flow auth เดียวกัน — endpoint OTP/email ยังไม่ระบุใน API_Specification_v1_

## Edge Cases
- ยกเลิก/ปฏิเสธสิทธิ์ LINE → กลับหน้า Login พร้อม toast
- เบอร์/อีเมลผิดรูปแบบ → ขึ้น error ใต้ฟิลด์
- เครือข่ายล่ม / timeout → แสดง error + ปุ่มลองใหม่
- กำลังเรียก API → ปุ่มแสดง loading และกันกดซ้ำ

## Success Criteria
- ล็อกอินสำเร็จทั้ง 3 ช่องทางและได้ session ที่ใช้งานได้
- ผู้ใช้เดิมเข้า Home ได้ใน 1 ขั้นตอน, ผู้ใช้ใหม่ถูกพาไปสมัคร/ผูกบัญชี
- ทุก error state มีข้อความภาษาไทยและทางออกให้ผู้ใช้
