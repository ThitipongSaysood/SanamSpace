# CUS-AUTH-003 · Register

## Objective
หน้าสมัครสมาชิกสำหรับผู้ใช้ใหม่ กรอกข้อมูลโปรไฟล์ให้ครบเพื่อเปิดบัญชีลูกค้าและเริ่มจองสนาม

## User Story
> As a **ลูกค้าใหม่ (Customer)**, I want **กรอกชื่อและเบอร์โทรเพื่อสมัครสมาชิก**, so that **มีบัญชีของตัวเองสำหรับจองสนามและสะสมสิทธิประโยชน์**.

## Entry Point
- กดลิงก์ "ยังไม่มีบัญชี? สมัครสมาชิก" จาก Login (CUS-AUTH-001)
- ถูกส่งมาจาก LINE Login (CUS-AUTH-002) เมื่อยังไม่มีบัญชี/ข้อมูลไม่ครบ

## Exit Point
- สมัครสำเร็จ → Home (CUS-HOME-001)
- มีบัญชีเดิมตรงกัน → Account Link (CUS-AUTH-004)
- กดย้อนกลับ → Login (CUS-AUTH-001)

## Components
- ฟิลด์ ชื่อ-นามสกุล
- ฟิลด์ เบอร์โทรศัพท์ (+ ปุ่มขอ OTP)
- ฟิลด์ อีเมล (ไม่บังคับ)
- Checkbox ยอมรับเงื่อนไขการใช้งาน/PDPA
- ปุ่มหลักสีเขียว "สมัครสมาชิก"

## Validation Rules
- ชื่อ-นามสกุล: ไม่ว่าง
- เบอร์โทร: ตัวเลข 10 หลัก ขึ้นต้น 0 และต้องไม่ซ้ำกับบัญชีเดิม
- อีเมล: ถ้ากรอกต้องเป็นรูปแบบ email ถูกต้อง
- ต้องติ๊กยอมรับเงื่อนไขก่อนกดสมัคร

## API Dependencies
- `POST /auth/line/login` — สร้าง session กรณีสมัครต่อจาก LINE
- `PUT /customers/{id}` — บันทึก/อัปเดตข้อมูลโปรไฟล์ลูกค้า
- `GET /auth/me` — ดึงข้อมูลบัญชีหลังสมัคร

## Edge Cases
- เบอร์/อีเมลซ้ำกับบัญชีเดิม → แนะนำให้ผูกบัญชี (CUS-AUTH-004)
- OTP หมดอายุ/ใส่ผิด → error ใต้ฟิลด์ + ปุ่มขอ OTP ใหม่
- ยังไม่ติ๊กยอมรับเงื่อนไข → ปุ่มสมัคร disabled
- เครือข่ายล่ม/บันทึกไม่สำเร็จ → error + ลองใหม่ โดยคงค่าที่กรอกไว้

## Success Criteria
- สร้างบัญชีลูกค้าใหม่และได้ session ที่ใช้งานได้
- ข้อมูลที่กรอกถูกบันทึกครบและแสดงในโปรไฟล์
- ทุกฟิลด์มี validation และข้อความ error ภาษาไทยชัดเจน
