# CUS-PKG-003 · My Packages

## Objective
- แสดงแพ็กเกจที่ลูกค้าซื้อแล้ว: ชั่วโมงคงเหลือ, วันหมดอายุ, สถานะ (ใช้งานได้/หมดอายุ/ใช้หมด)
- ให้ลูกค้าเลือกใช้สิทธิแพ็กเกจตอนจองสนาม และดูประวัติการใช้

## User Story
> As a **Customer**, I want **ดูแพ็กเกจของฉันและชั่วโมงคงเหลือ**, so that **รู้สิทธิที่เหลือและนำไปใช้จองสนามได้ก่อนหมดอายุ**.

## Entry Point
- จาก CUS-PKG-001 (Package List) ลิงก์ "แพ็กเกจของฉัน"
- จาก Profile (CUS-PROFILE-001) เมนู "แพ็กเกจของฉัน"
- หลังซื้อสำเร็จจาก CUS-PKG-002

## Exit Point
- กด "ใช้สิทธิจอง" → CUS-BOOK-001 (Create Booking) แบบ pre-select แพ็กเกจ
- กดแพ็กเกจ → รายละเอียด/ประวัติการใช้สิทธิ
- ย้อนกลับ → จอต้นทาง

## Components
- แท็บ/ตัวกรอง: ใช้งานได้ / หมดอายุ / ใช้หมด
- การ์ดแพ็กเกจของฉัน: ชื่อ, ชั่วโมงคงเหลือ/ทั้งหมด (เช่น 12/20 ชม.), progress bar, วันหมดอายุ
- ป้ายสถานะ + ป้ายเตือน "ใกล้หมดอายุ"
- ปุ่ม "ใช้สิทธิจอง"
- ประวัติการใช้สิทธิ (รายการหักชั่วโมงต่อการจอง)
- Empty state เมื่อยังไม่มีแพ็กเกจ

## Validation Rules
- ชั่วโมงคงเหลือ/วันหมดอายุดึงจาก API ไม่คำนวณค้างฝั่ง client
- แพ็กเกจหมดอายุหรือชั่วโมงเหลือ 0 → ปุ่ม "ใช้สิทธิจอง" ถูก disable
- แสดงเฉพาะแพ็กเกจของลูกค้าที่ล็อกอิน (ตาม tenant)
- เตือน "ใกล้หมดอายุ" เมื่อเหลือ ≤ จำนวนวันที่สนามกำหนด

## API Dependencies
- `GET /api/v1/customers/{id}` — สิทธิแพ็กเกจที่ผูกกับลูกค้า
- — (รายละเอียดการหักชั่วโมงผ่าน Booking ของ tenant)

## Edge Cases
- ยังไม่มีแพ็กเกจ → empty state พร้อมปุ่มไป CUS-PKG-001
- โหลดล้มเหลว → error + ปุ่ม "ลองใหม่"
- แพ็กเกจหมดอายุระหว่างดู → ย้ายไปแท็บ "หมดอายุ" อัตโนมัติเมื่อรีเฟรช
- ชั่วโมงไม่พอสำหรับ slot ที่จะจอง → แจ้งเตือนตอนเข้า Booking
- ออฟไลน์ → แสดง cache พร้อมป้าย "ออฟไลน์"

## Success Criteria
- แสดงแพ็กเกจที่ซื้อพร้อมชั่วโมงคงเหลือและวันหมดอายุถูกต้อง
- ตัวกรองสถานะทำงานถูกต้อง
- "ใช้สิทธิจอง" นำไป CUS-BOOK-001 เฉพาะแพ็กเกจที่ใช้งานได้
- ประวัติการใช้สิทธิแสดงการหักชั่วโมงตรงกับการจอง
