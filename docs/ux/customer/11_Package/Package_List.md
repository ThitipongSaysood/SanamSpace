# CUS-PKG-001 · Package List

## Objective
- แสดงรายการแพ็กเกจชั่วโมงที่สนามเปิดขาย: 10 Hours, 20 Hours, 50 Hours, Monthly
- ให้ลูกค้าเปรียบเทียบราคา/จำนวนชั่วโมง/ความคุ้มค่า แล้วเลือกดูรายละเอียดเพื่อซื้อ

## User Story
> As a **Customer**, I want **ดูแพ็กเกจชั่วโมงทั้งหมดที่สนามมี**, so that **เลือกแพ็กเกจที่คุ้มค่าและเหมาะกับการใช้งานของฉัน**.

## Entry Point
- จาก Home (CUS-HOME-001) Quick Action / แบนเนอร์ "แพ็กเกจ"
- จาก Profile (CUS-PROFILE-001) เมนู "แพ็กเกจ"

## Exit Point
- กดแพ็กเกจ → CUS-PKG-002 (Package Detail)
- กด "แพ็กเกจของฉัน" → CUS-PKG-003 (My Packages)
- ย้อนกลับ → จอต้นทาง

## Components
- การ์ดแพ็กเกจ: ชื่อ (10/20/50 Hours, Monthly), จำนวนชั่วโมง/สิทธิ, ราคา, ป้าย "คุ้มสุด"/ส่วนลด
- ราคาเฉลี่ยต่อชั่วโมง เพื่อเปรียบเทียบความคุ้มค่า
- ตัวกรอง/หมวด (ถ้ามีหลายกีฬา/หลายสาขา)
- ลิงก์ "แพ็กเกจของฉัน"
- Empty state เมื่อสนามยังไม่เปิดขายแพ็กเกจ

## Validation Rules
- แสดงเฉพาะแพ็กเกจที่สนาม (tenant) เปิดใช้งานและอยู่ในช่วงจำหน่าย
- ราคาและจำนวนชั่วโมงดึงจาก config สนาม ไม่ hardcode
- รายการเรียงตามลำดับที่สนามกำหนด (หรือจากชั่วโมงน้อยไปมาก)

## API Dependencies
- — (ใช้ catalog แพ็กเกจของ tenant; เชื่อมกับ Membership/Wallet เมื่อชำระ)

## Edge Cases
- ไม่มีแพ็กเกจเปิดขาย → empty state "ยังไม่มีแพ็กเกจ"
- โหลดล้มเหลว → error + ปุ่ม "ลองใหม่"
- แพ็กเกจหมดช่วงโปร/หมดสิทธิ → แสดงป้าย "หมดเวลา" หรือซ่อน
- ราคา/สิทธิเปลี่ยนระหว่างดู → รีเฟรชก่อนเข้า Detail
- ออฟไลน์ → แสดง cache พร้อมป้าย "ออฟไลน์"

## Success Criteria
- แสดงแพ็กเกจ 10/20/50 Hours และ Monthly ตาม config สนาม
- ราคา/จำนวนชั่วโมง/ความคุ้มค่าแสดงถูกต้อง
- กดเข้า Detail (CUS-PKG-002) และเข้า My Packages (CUS-PKG-003) ได้
- กรณีไม่มีแพ็กเกจแสดง empty state ชัดเจน
