# Prototypes

เก็บไฟล์ prototype (เช่น Figma `.fig` หรือลิงก์) แยกตามฝั่ง: `customer/` · `owner/` · `super-admin/`

## Naming Standard

```
PT-<APP>-v<version>.fig
```

| App | ตัวอย่าง |
|---|---|
| Customer | `PT-CUS-v1.fig` |
| Owner | `PT-OWN-v1.fig` |
| Super Admin | `PT-ADM-v1.fig` |

> ถ้า prototype อยู่บน Figma cloud ให้สร้างไฟล์ `.md` คู่กันเก็บลิงก์ + เวอร์ชัน แทนการ commit ไฟล์ `.fig` ขนาดใหญ่
