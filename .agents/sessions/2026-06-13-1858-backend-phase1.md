# Backend Phase 1 — Core API (PHP/Laravel + MySQL→SQLite dev)

## Goal
เริ่มทำ backend จริงตาม structure (เลือก PHP+MySQL ตาม System Architecture) เพื่อปลดล็อก
ให้ customer app สลับ mock→/api/v1 ภายหลัง

## Decisions
- Stack: **Laravel 13 + PHP 8.4** (โครงโฟลเดอร์ใน Project_Structure = ทรง Laravel)
- Dev DB: **SQLite** (zero-config, รันทันที); prod = MySQL ผ่าน .env (MySQL 9.6 ติดตั้งในเครื่องแล้ว)
- API prefix `/api/v1`, auth = **Sanctum** (LINE login ออก token บน Customer model; admin login บน User)
- Response = API Resources **camelCase** ตรง shape `frontend/lib/types.ts` (venueId = org slug) → swap ง่าย
- ⚠️ list/single responses ถูกห่อ `{ "data": ... }` (Laravel default) → ตอน swap frontend ต้อง unwrap `.data`
